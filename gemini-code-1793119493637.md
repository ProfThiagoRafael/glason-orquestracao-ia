# 🚀 GLASON.IA — Arquitetura de Orquestração de IA Comercial B2B (Multi-Agente)

## 📋 Visão Geral

O **GLASON.IA** é uma plataforma corporativa autônoma de automação comercial e orquestração de Inteligência Artificial para atendimento e vendas B2B via WhatsApp (Cloud API). Projetado sob arquitetura **SaaS Multi-tenant** para cenários de alta escala (capacidade para repositórios superiores a **20 milhões de contatos**), o sistema utiliza uma infraestrutura baseada em **PostgreSQL**, **Redis** e **n8n em Queue Mode**.

A solução implementa uma **hierarquia multi-agente** supervisionada por uma orquestradora de governança que coordena quatro agentes comerciais especializadas por alçada, além de rotear demandas multidepartamentais no mesmo canal.
